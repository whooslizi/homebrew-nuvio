# homebrew-nuvio

Homebrew tap for [Nuvio Desktop](https://github.com/NuvioMedia/NuvioDesktop) on macOS.

## Why

Nuvio doesn't provide updates via [Homebrew](https://brew.sh) (yet), so this tap fills the gap. A GitHub Actions bot keeps the cask in sync with every new Nuvio release, and you install and upgrade it like any other Homebrew app.

## How this works

1. Every 6 hours, a GitHub Actions workflow checks the latest release on [NuvioDesktop releases](https://github.com/NuvioMedia/NuvioDesktop/releases) (pre-releases included, since Nuvio currently ships as alpha).
2. If there's a new version, it downloads the macOS builds (Apple Silicon and Intel, or universal), computes their SHA-256 checksums, and reads the app name and bundle ID from the build.
3. It regenerates `Casks/nuvio.rb` and commits it as `github-actions[bot]`.
4. On your Mac, `brew upgrade` picks up the new version, quits Nuvio if it's open, replaces the app in `/Applications`, and removes the Gatekeeper quarantine flag.

## Installation

```bash
brew tap whooslizi/nuvio
brew install --cask nuvio
```

## Update

```bash
brew update && brew upgrade --cask nuvio
```

## Auto upgrade daily

Uses [homebrew-autoupdate](https://github.com/DomT4/homebrew-autoupdate):

```bash
brew tap domt4/autoupdate
brew trust --command domt4/autoupdate/autoupdate
brew autoupdate start 1d --upgrade --greedy --cleanup --immediate
```

Check status:

```bash
brew autoupdate status
```

Stop it:

```bash
brew autoupdate stop
```

Note: Homebrew quits Nuvio before upgrading but doesn't reopen it afterwards.

## Uninstall

```bash
brew uninstall --cask nuvio
brew untap whooslizi/nuvio
```

## Repo layout

```
homebrew-nuvio/
├── .github/workflows/update.yml      scheduled bot
├── .github/scripts/update-cask.sh    generates the cask
└── Casks/nuvio.rb                    generated by the bot
```

To force a refresh, go to **Actions > Update Nuvio cask > Run workflow** and tick **force**.
